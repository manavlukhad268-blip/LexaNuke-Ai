# Project Scope: LexNuke AI

## In Scope (Hackathon MVP)

- **User Interface:** Dark-themed responsive web dashboard for mobile and desktop screens.
- **Input Methods:** Web URL input field and file attachment upload zone.
- **Forensic Simulation:** Simulated AI confidence score for deepfake breach assessment.
- **Hashing & Verification:** Generation of court-ready SHA-256 mock hashes and timestamp tokens.
- **Legal Engine:** Dynamic templating for legal cease-and-desist notices under digital copyright laws.
- **Trigger Actions:** Simulated email dispatch confirmation toast for host-level takedown requests.

## Out of Scope (Future Releases)

- Real-time deepfake model training on live video streams.
- Direct API integration with domain registrars (WHOIS automation).
- Multi-jurisdictional automated legal filing beyond standard copyright & IT frameworks.
